# NutriBowl 🥗

### Smart Recipe Finder

NutriBowl is a Python and Streamlit-based recipe finder that suggests meals using available ingredients.

**Features**
- Ingredient-based recipe matching
- 200 recipe suggestions and variations
- Estimated calories, protein, carbohydrates and fats
- Ingredient substitution suggestions
- Adjustable ingredient-match threshold
